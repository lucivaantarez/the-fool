HIGHSPEC.GG — DIRECT API

Submit jobs with your own API

Fire captcha and face-scan jobs straight into the queue from your own program, authenticated by your personal API key — no login. It charges your in-app balance exactly like the web.

BASE URL https://api.highspec.gg/api/v1

01 Authentication

Every request must include your API key (starts with hsk_). Use any method — the system reads them in this order:

MethodExample
Query string?api_key=hsk_xxxxx
HeaderX-API-Key: hsk_xxxxx
BearerAuthorization: Bearer hsk_xxxxx
Keep it secret

Anyone with this key can submit jobs and spend your balance. If it leaks, generate a new one on the API Keys page — the old key stops working immediately.

02 Submit a captcha job

POST /external/job/captcha/submit?service=directapi
Request
{
  "note": "Horst Rejoin",
  "accounts": [
    {
      "username": "highspecgg",
      "cookie": "_|WARNING:-DO-NOT-SHARE-THIS.|XXXX"
    },
    {
      "username": "highspecgg2",
      "cookie": "_|WARNING:-DO-NOT-SHARE-THIS.|XXXX"
    }
  ]
}
Response · 201
{
  "status": 201,
  "message": "job submitted",
  "data": {
    "id": "3bfc793b-7c28-4e9a-86c8-…",
    "status": "PENDING",
    "total_accounts": 2,
    "total_amount": 4,
    "note": "[DirectAPI] Horst Rejoin",
    "priority": false,
    "is_api": true,
    "api_by": "directapi",
    "queue_position": 0,
    "created_at": "2026-07-27T11:21:25Z"
  }
}
Keep the id

data.id is the job id, returned immediately — keep it to check status in section 05. total_amount is what was charged, in satang (4 = 0.04 THB).

FieldDetails
accountsRequired List of accounts; multiple per job, at least one.
accounts[].usernameRequired Roblox username
accounts[].cookieRequired The .ROBLOSECURITY cookie — no password needed, we don't store it.
noteOptional A label for the job — which bot/run it came from; shown in your job history.
Dedup

Accounts still pending in an earlier job (PENDING / PROCESSING) are skipped automatically and not double-charged — safe to retry. If every account in the request is already in flight, you get a 409 and no new job is created.

03 Submit a face-scan job

POST /external/job/face-scan/submit?service=directapi

Exactly like the captcha job — same payload; note, x2, and dedup all work the same. It just goes to the face-scan tool instead.

04 Turn x2 on / off

Add &priority=true to the URL to enable x2 (priority) — the job is picked up before the normal queue, for double the charge. Leave it off (or false) for the normal queue at the normal price.

x2 off — normal queue
POST /external/job/captcha/submit
     ?service=directapi
     &api_key=hsk_xxxxx
x2 on — priority
POST /external/job/captcha/submit
     ?service=directapi
     &api_key=hsk_xxxxx
     &priority=true
Billing

You are charged at submit, by the number of accounts actually queued (after dedup). Accounts that fail are auto-refunded — see refunded_amount.

05 Check job status

Append the id from submit (section 02) to the URL.

GET /external/job/:id
Response · 200
{
  "data": {
    "id": "c8479853-1284-4a99-8267-…",
    "status": "COMPLETED",
    "total_amount": 100,
    "success_amount": 92,
    "fail_amount": 5,
    "skip_amount": 3,
    "refunded_amount": 16,
    "note": "[DirectAPI] Horst Rejoin",
    "priority": false
  }
}
status — exactly 4 values
PENDINGqueued
PROCESSINGrunning
COMPLETEDfinished (terminal)
FAILEDwhole job failed, refunded (terminal)

Poll until status = COMPLETED or FAILED (both terminal — they don't change again).

Read carefully

COMPLETED means the job finished — not that every account succeeded. A job where all accounts fail is still COMPLETED. Always check success_amount / fail_amount for the real result, never just status.

You can only read your own key's jobs; another user's job returns 404 as if it doesn't exist.

Want to know which IDs succeeded and which failed (per ID, not just totals)? Append /accounts to the URL.

GET /external/job/:id/accounts
Response · 200
{
  "data": {
    "accounts": [
      { "combo": "user1:pass:cookie", "status": "COMPLETED" },
      { "combo": "user2:pass:cookie", "status": "FAILED" }
    ]
  }
}
Filter (optional)
?status=success   → only succeeded
?status=fail      → only failed
?status=skip      → only skipped

Per-line status: COMPLETED / FAILED / SKIP / FACE_LOCK / COOKIE_BROKEN

06 Check balance

GET /external/balance
Request
curl -H "X-API-Key: hsk_xxxxx" \
  https://api.highspec.gg/api/v1/external/balance
Response · 200
{ "data": { "points": 179890 } }
Unit

points are in satang — divide by 100 for THB. e.g. 179890 = 1,798.90 THB.

07 Limits & error codes

Limit 150 requests/second (burst 300) per key, not per IP. Hammering from one machine is fine and won't get the IP blocked.

CodeMeaningWhat to do
400Bad payload or insufficient balanceCheck username/cookie and your balance
401Missing or invalid keyCheck the key on the API Keys page
409All accounts already in an earlier jobWait for the earlier job to finish, then resubmit
429Too many requestsWait per Retry-After (1 second) and retry
503Tool temporarily disabledTry again later
